# Brix Design Studio Portal

A client portal for Brix Design Studio. One home for project files, brand guidelines, and communication between the studio team and clients, so nothing lives in scattered drives and email threads.

## What it does

- **Sign in** with Google or email and land on a dashboard built for your role.
- **Dashboard**: active projects, recent files, open tasks, upcoming meetings, and an activity feed at a glance.
- **Phases**: see where each project stands, from kickoff to delivery.
- **Design**: a workspace for work in progress.
- **Documents**: project files stored and organized for quick retrieval, with a thumbnail on every file.
- **Asset & Brand Library**: logos, fonts, and templates in one place, ready to reuse across projects.
- **Guidelines**: the studio's brand style guide, typography, and color rules, so anyone applying the brand gets it right.
- **Module Library**: reusable design system building blocks for websites.
- **Meetings**: schedule and track calls with the studio.
- **Asset requests**: ask for new materials and follow their status.
- **Assistant**: an AI chat for quick questions about a project, with file attachments.
- **Settings**: profile, notifications, and connected tools.

## Roles

- **Admin** manages members, invitations, and roles.
- **Designer** uploads and manages project files and tasks.
- **Client** views their own projects, downloads assets, comments, and approves.

## Marketing site

Alongside the portal, this repo also builds Brix Design Studio's public site: home, work, news, archive, about, and contact pages, plus a client portal landing page that introduces the product above to prospective clients.

## Tech stack

React 19, TanStack Start and TanStack Router, Vite, Tailwind CSS v4, Supabase (database, auth, storage), and the Vercel AI SDK.

## Development

```sh
bun install
bun run dev
```

Runs at [http://localhost:8080](http://localhost:8080).
